# Pattern Generator & Number Analyzer

A beginner-friendly Python program that combines **pattern generation** and **number analysis** in one menu-driven application.

## 📌 About the Project

This project is created to practice basic Python concepts such as **loops, conditions, user input, operators, and logical thinking**.

## ✨ Features

* ⭐ Generate a Star Pattern
* 🔢 Check Even & Odd Numbers
* ➕ Calculate Total of a Number Range
* ⚠️ Handle Invalid Input
* 📋 Simple Menu-Driven Program

## 🧠 Concepts Used

* `while` loop
* `for` loop
* `if-elif-else`
* `input()`
* `range()`
* `%` Modulus Operator
* `break` & `continue`
* Input Validation

## ▶️ How It Works

**1. Generate Pattern**
Takes the number of rows and generates a star pattern.

**2. Analyze Numbers**
Takes a starting and ending number, checks each number as Even or Odd, and calculates the total.

**3. Exit**
Ends the program with a goodbye message.
